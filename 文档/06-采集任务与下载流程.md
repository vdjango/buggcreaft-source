# 采集任务与下载流程

## 输入与执行

单任务输入：HTTPS 文件 URL、可选 expected_hash + 算法（SHA-1/256/512）、可选 source_provider/source_file_id。不接受 description、translated_name、dependencies 等字段。批量输入为 JSONL，每行同一 DTO，CLI 只入队；来源自动发现留给后续目录适配器。

流程：API 校验域名和字段 → 事务写 queued → worker 领取并发租约 → 流式写 .part 并计算摘要 → 完整下载后检查预期摘要 → 发布本地 CAS JAR → 从本地 ZIP 受限解压元数据 → 保存证据文件 → parser 构造声明清单 → 同一事务保存 artifact/scan 并标记 succeeded。

`succeeded` 仅代表任务结束；完整性看 scan.status。失败不会返回成功空清单。本轮同解析器+强摘要请求可跨 URL 合并在途任务并复用完成快照；无摘要/SHA-1 按完整 URL 合并在途、完成态仍需下载。下载后 SHA-256 相同才复用已存快照。合并保留首次来源，不声称记录了所有来源，详见第 25 号。

## 状态与恢复

`queued → running → succeeded/failed/cancelled`。退出时尚在执行的 worker 归还 queued；进程硬崩溃由 lease_until 到期回收，领取最多三次。正常业务失败停在 failed，由用户 retry 新建任务保留原历史。重试不自动依赖上游错误正文判断，不盲目重试损坏包和摘要冲突。后续目录调度可加带随机抖动的网络退避，不能重复业务状态机。

每次领取有新 claim_token；pulse 和 finish 必须匹配当前 token、running 和未过期租约。取消在 checkpoint 检测；完成事务再次检查 cancel_requested，防止取消之后写成功。心跳最短间隔 1 秒，不每个字节都写数据库。

## 网络与解压限制

- 默认只允许 cdn.modrinth.com、edge.forgecdn.net、mediafilez.forgecdn.net、media.forgecdn.net，HTTPS 443，无用户信息。每次重定向重新校验，同样策略最多四次请求。域名白名单只能由可信运维修改，不能接受用户自定义代理/回源域名；自建域名需另外完成 DNS/IP 固定和出口策略。
- 下载最多 256 MiB、单操作超时 20 秒、连接超时 10 秒、总时限目标 180 秒。总时限在流块检查，最坏可能再等待一次 socket 超时。拒绝 HTTP 编码压缩，避免字节哈希对象与实体混淆。
- ZIP 最多 50,000 条目，单元数据 1 MiB，总解压预算 128 MiB，递归深度 4，容器总数 128，压缩比最大 300。超过限制明确失败/partial，不静默裁剪结果。
- 只解压已知元数据和已声明嵌套 JAR；不按成员名写磁盘，证据按摘要存储。拒绝路径穿越、重复条目、符号链接、加密成员，读取选中成员时校验 CRC。禁止 extractall、执行脚本、Java 反射或动态导入模组代码。

当前 API 不提供本地路径读取；只有本机可信 CLI 的 import-local 接受已有 JAR/目录，并先复制到 CAS。测试真实整合包目录时不会修改原文件。

默认准入上限 1,000、全局运行上限 4、日下载预算 20 GiB、磁盘保留 512 MiB；按需优先于显式 warmup。每次网络下载前原子预留单文件上限，失败不退；缓存不重复下载或解析。manifest 每批默认 100 行，超限非零退出且保留已入队前缀。完整规则、共享取消语义及验收见第 25 号；不会自动全站追溯或人工维护依赖图。
