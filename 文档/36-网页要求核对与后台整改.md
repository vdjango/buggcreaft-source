# 网页要求核对与后台整改

2026-11-11。用户追加部署授权后，新版官网、账号和源站已上线。本文保留整改前及本地阶段记录以便追溯，当前状态以末节“实际域名部署验收”为准；历史 502 和“本窗口不部署”不是当前结论。

## 整改前问题记录（历史）

原依赖工作台与平台分别启动 Vue Router，独立根 CSS 维持另一套外壳；将二者接入同一菜单不能算统一后台。后台菜单曾把 `/` 和 `/search` 公开页面作为管理功能，导致离开后台。主后台、设置与工作台缺少完整菜单点击回归。上述问题是实现与验收遗漏，没有保留两套后台的产品必要。

新版启动器实际风景截图与 DesignTokens.qml 显示风景背景、蓝灰玻璃面板、浅蓝操作按钮，同时保留中性控件色。源站暖白紫色改动、账户页和官网的部分新布局不能据此宣称已符合当前启动器整体视觉。需要按实际产品重新完成设计与逐页验收；不能仅将紫色换成蓝色就标记完成。

## 本轮源码变更及交付限制

管理路由仍保留原地址，服务端使用统一 render_shell 输出 admin-workbench 入口及服务端认证种子；公开搜索使用单独页面组件，属于公开导航。工作台业务 store 与 API 沿用原所有者，仅删除重复外壳、根主题、第二套导航与独立令牌表单。设置页“来源表现”修正为运维质量页；旧翻译配置镜像 hash 入口改为具体设置页，避免经总览丢失目标。

前序 `minecraft-tunnel-native/validation-artifacts/web-handoff/source-web.tar.gz` 是此轮修改之前的快照，不能作为本次整改包发布。本轮还改了服务端路由，后续发布必须同时包含相应源码与重新构建资产，不能只替换旧网页包。未部署、未完成整体验收。

## 本轮本地整改结果

当前源站后台已统一为平台 Router、SiteNav、AdminNav、AdminAccess 与同一蓝灰根主题；五组菜单分别承载内容、作业、运维、接入和设置。资源索引管理仍可保留，但公开 `/search` 和 `/` 已移出后台菜单。八个原工作台业务页在同一 SPA 中显示，独立入口、重复登录和主题切换已移除。玩家镜像首页改为实际游戏风景卡片，删除旧纸卡装饰；管理界面使用低对比风景背景、玻璃侧栏、浅色内容卡与蓝色操作。没有修改生产配置、数据或分发所有权。

运行 Edge，完整 34 路由生成 97 张桌面/手机及补充截图，实际逐张查看；菜单实点检查五组及全部子菜单，同一 JS 页面状态保留，目标/高亮正确，移动菜单点击后关闭。随后复查八个原工作台页面及登录/安装/详情/表单底部共 25 张截图。修复公共 main 的自动外边距导致后台垂直居中、全局路由捕获器吞掉移动菜单收起行为、登录按钮残留紫色，以及大标题与异常留白。证据：data/visual-migration/manifest.json、manifest-recheck.json、navigation.json 与 scenic-final.log/scenic-workbench-final.log。表格在手机容器内滚动，不要求把原始声明压缩至不可读宽度。

官网、教程和账号页面同步采用新版启动器实际风景与蓝灰视觉，真实三张启动器界面错落叠放。统一账号的伙伴云可点击查看共同记录，并按真实最后共同连接时间呈现久未联系伙伴；无好友或缺少历史分别显示诚实空态，绝不推断好友离开。原生 C++ TLS/WebCrypto/SMTPS 夹具验证注册、失败重试、设备授权撤销、邮箱恢复和六位新密码；活动仍是联机连接估算，不是完整 Minecraft 进程游玩史。

本地完成不等于线上完成：本窗口不部署。发布接续见节点项目 docs/50-网站运维/06-账号纪念页与源站改版交付.md 及 validation-artifacts/web-handoff/README.md。公开域名最新版、真实邮件收件箱、真实玩家好友/跨节点邀请仍待服务器窗口验收。源站现有后端仍为 Python，不能将本轮网页改版宣称源站已全 C++ 化，也不能以网页测试代替全架构性能报告。


最后补充：节点邀请文案中遗留的“节点网页后台”路径已从组件和 store 反馈一并删除；邀请码真实生成后遮盖截图，桌面/手机查看并修正浅橙文字对比度。原生节点领取源站邀请的完整能力不由此网页测试证明，需节点版本支持。补充截图与记录为源站 data/visual-migration/manifest-invitation.json、scenic-invitation.log。完整工作台复查图摘要另见 manifest-workbench.json。
