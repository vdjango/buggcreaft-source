# 正文全文、语义与多节点实施契约

> 2026-11-09，实现基线；本页细化并取代第 22–24 号中与当前代码不同的草案。验收与未完成项见末尾。

## 本次决定

复用 mc_translate 的资源快照、当前 source_hash/context/policy 匹配译文、HTML 文本清洗与节点审批。新增搜索投影而不重写目录/翻译，不写入 JAR 事实。PostgreSQL 18 + GIN 全文 + pg_trgm 名称近似 + pgvector 精确余弦基线；jieba 统一查询和文档分词。独立 FastEmbed/ONNX Runtime 推理进程，不在 API 下载模型或计算文档向量。先用小型中文 BGE 模型做 CPU 基线，模型文件摘要固定空间，不冒充原规划 BGE-M3 的质量。

公开搜索独立 /search 页面；管理索引作业放作业，索引覆盖放运维，部署/模型配置通过环境配置。不同页面不混放设置和内容。共享 Axios/Vue Router/Pinia，旧目录仍兼容。

## 多节点拓扑与权威

一个目录 hub 写自己的 SQLite；搜索 API 副本和索引 worker 共用同一个 PostgreSQL 主库。不是多个节点共享 SQLite 文件，也不是请求时遍历多个上游搜索。hub 事务触发器写持久单调事件和当前可见性，现存目录一次回填；译文发布/撤回及删除同样产生事件。feed epoch 防止换库后沿用旧游标。

摄取租约位于 PostgreSQL；只有当前持有者推进 feed 游标，项目任务按版本合并。worker 使用 SKIP LOCKED、领取 token、数据库时间及到期租约；网络/推理不占数据库事务。发布必须检查 token/源修订，旧任务不得覆盖新头。失败重试有上限并可显式重建。先按项目原子更新，配置/模型变化重建，未完成新版本不与旧向量混用。

所有搜索路径、相似资源、分页都会向目录权威批量复核当前修订和可见性；不可达时失败关闭，不从过期副本返回被撤回文本。索引异步更新期间允许少结果，不返回错版本。分页引用保存在共享数据库，随机游标绑定查询/筛选/模式/语言/版本/到期时间，因此不要求负载均衡粘滞。镜像节点只代理受控搜索只读端点，不缓存搜索响应、不转发用户 Cookie/管理令牌；hub 不可达返回不可用。

内部导出默认仅 loopback+共享密钥。跨主机通过 TLS 私网网关转发至同机回环 hub，网关只开放所需内部接口并限制来源网段；自定义非回环直连 aiohttp TLS 时还须显式启用远程导出。现有公网 Nginx 继续屏蔽 /_internal/。推理同样有独立密钥/并发与输入预算；模型不下发给镜像。

## 一致性、预算与公开行为

全文包括标题、简介、原文正文及当前可发布译文，正文按有界窗口切块、保留语言/哈希/版本和真实片段。超过正文/块预算明确标记 truncated；查询绑定参数，限制字数/词数/候选窗口/分页 TTL/推理并发。MC 版本和加载器必须由同一 release 同时满足，不拼接项目级标签。语言参数优先展示该语言标题/正文预览，不是排除其他语言原文的过滤器。

语义用真实模型向量，核对空间摘要、维度、有限数与单位化；混合按项目 RRF 排序，语义断开显示降级，纯语义请求返回 503。相近功能不代表依赖兼容，依赖状态保持未核验。首版不宣称 ANN、高并发 SLO、百条人工留出集质量评测或多机容灾已完成。

## 当前数据与算法

Alembic 0005 只在 PostgreSQL 建六表：search_control（epoch/摄取水位/租约）、search_projects（当前快照和原子头）、search_jobs（每项目合并任务）、search_chunks（字段/语言/块/tsvector/vector）、search_sessions（共享候选分页）、search_rate_limits（共享分钟限额）。GIN 覆盖 tokens 与 title trigram。SQLAlchemy Engine/短事务复用，不另建连接池/队列框架；语义目前精确余弦，无 ANN。

SearchExport 复用 Store 的快照/当前 context、POLICY、source_hash 译文选择；SQLite 三表和触发器保证新增/更新/删除、译文发布/撤回、可见性变更与业务同事务。没有独立全站爬虫：只索引本站已收录内容，不承诺 CurseForge/Modrinth 全站覆盖或平台间自动去重。

jieba 0.42.1 加小型 MC 词典；文档用搜索分词并补中文二元词，查询用准确分词、停用词、内容词 AND。交集在同一 256 字符块内成立；跨远距离段落的多个词未保证同项目合取。每块重叠 32 字符，每字段读取上限 400000 字符，项目清洗后总上限 200000 字符，超限 coverage.truncated=true。清洗复用 HtmlText/MarkdownIt；不执行网页或 JAR。名称精确/项目 ID/slug 提升，pg_trgm 只近似名称；不把任意正文子串 SQL LIKE 当全文。索引/查询逻辑属于 text.py，改规则必须改变 TEXT_REVISION 并重建。

RRF 常数 60，名称精确路由权重 5，其他权重 1，按项目去重，最多 200 候选；片段来自实际命中块，语义命中名称/简介时追加单独标识的真实正文预览。高亮为 Unicode 码点区间和 Vue 文本插值，不注入 HTML。相似接口用原项目实际正文前 200 字的查询向量，排除自身；不把共同前置当功能相近，也未实现多原型/全正文向量聚合。当前没有经过质量标注的最小相似度阈值，语义排序可能含不相关尾部结果；相关度不能当置信度。

分页会话五分钟、查询最多 200 字/32 词、每页 1–50 条，模型推理批次 16、输入最多 1000 字且不超 510 token。每页按所需条数分批加载/复核，避免首屏取回所有候选全文和向量；空结果也复核 epoch。长查询超过词预算只保留前 32 词。数据库候选查询 statement_timeout 2500ms。公开响应 no-store，镜像既不读缓存也不写缓存；同一在途只读请求仍可合并。普通用户哈希身份 120 次/分钟、批准镜像聚合 1200；跨进程由 PG 计数，未认证自报身份不采信。

## 模型与复现

独立 FastEmbed 0.7.4 + CPU ONNX Runtime，BAAI/bge-small-zh-v1.5，512 维。准备命令取 Qdrant ONNX 仓库不可变提交 46fbe35fd4374a00fee7de77dfddaeb6dd6a2c59；本机五文件清单 revision 为 99f12e113be380bdc60848acf108561ef3157f427b47538378967d7ef47418d7。默认官方源；本机网络不能连官方下载，验收显式选择 hf-mirror.com，运行过程离线核对文件，不自动下载。HTTP 客户端固定服务地址、独立密钥、无环境代理/重定向，向量核对 revision/维度/有限数/归一化。

运行与升级步骤见 [deploy/SEARCH.md](../deploy/SEARCH.md)。模型依赖仅在 requirements-embedding.lock，普通服务仍使用 requirements.lock。同一库的 API/worker 必须同配置；先停旧 worker 再升级并 search-rebuild。项目原子替换期间可能少结果，尚未实现双代次无中断切换。目录换库 epoch 不符时拒绝旧结果，需要明确 reset-source。事件暂无自动清理，不可擅自截断日志。

官方依据：[PostgreSQL 18 全文索引](https://www.postgresql.org/docs/18/textsearch-indexes.html)、[pgvector](https://github.com/pgvector/pgvector)、[FastEmbed 模型列表](https://qdrant.github.io/fastembed/examples/Supported_Models/)。具体本地效果以验收记录为准。

tests/test_search.py 七项覆盖真实正文独有词、HTML/Markdown 清洗、Unicode 高亮、当前译文/撤回、同 release 筛选、跨两个 API 游标、权限、分页过期、权威断开、feed epoch、八线程抢占、到期领取 token 和旧修订无法覆盖。显式合成向量仅用于编排单元验证，不作为语义质量证据。tests/platform/test_federation.py 新增真实 HTTP 镜像 → hub → 搜索后端，连续相同查询第二次立即反映撤回，不缓存、不转用户 Cookie/Authorization。原联邦审批/撤销测试继续通过。

真实模型进程使用准备的 512 维 ONNX，六个人工隔离资源、五条自然语言示例；tools/evaluate_search_smoke.py 实际走 /v1/search，未拦截 API。五条预期首项在 semantic/hybrid 均命中；词法对这五条改写语句没有预期首项，证明不是以关键词子串假装语义，但此样本并非独立留出集，不能推断泛化质量。完整查询、有效模式、前五结果和单次耗时保存在忽略的 data/search-preview/model-smoke.json；不报告 P95 或生产延迟承诺。可使用自己的标注 queries.json 再运行工具。

另实际停止推理进程再访问：hybrid 显示 degraded=true 和词法结果，semantic 返回 503；重新启动后恢复真实语义。未执行付费翻译模型调用，不把小型 embedding 与译文生成混为一事。
