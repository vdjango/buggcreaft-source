# 管理前端与组件规范

Vue 3 Composition API + TypeScript + Vue Router 4 + Pinia 3 + Axios + Vite；Vitest 验证共享状态与请求，Playwright 打开浏览器并按项目视觉 Skill 逐张查看截图。用户明确要求 Vue 全家桶和 Axios。自动符号索引见第 28 号。

## 共享实现

main.ts 注册 Pinia/Router 并挂载；api.ts request 是唯一 Axios 传输，含 Job/Scan/ArtifactPage/StorageStatus DTO；stores/collections.ts 负责内存会话、独立查询控制器和任务页轮询；DependencyTable 为各声明复用依赖表；labels.ts 共享状态、错误和容量格式；vite.config.ts 统一 Vue 插件及本地代理。实际签名由第 28 号生成，不手写一份过时的 App 方法列表。

令牌只放内存，不保存 localStorage；元数据通过 Vue 文本转义显示，不用 v-html。完整迁入后可使用平台 HttpOnly 管理会话，默认自动尝试 Cookie，仍保留内存 Bearer 备用；Cookie 写操作有 Origin 检查。细分 RBAC 尚未实现。完整名称缺失显示“包内未声明名称”，不假装那是上游项目名称。

## 迁入页面与后续增强

目录、项目、译文反馈/任务、来源/存储设置、账户及镜像页面已从原平台迁入；当前依赖领域六页如下，完整后台菜单见第 29 号。人工完整审核流、增强搜索等仍需后续实现。新领域独立成页，沿用共享请求/组件，不复制下载、状态或 parser。

搜索页面另有明确需求：名称/正文/译文全文、语义模式、功能相近资源、组合筛选、真实命中片段/高亮、来源折叠、索引覆盖/降级提示。组件职责、防抖/取消、迟到响应、稳定分页和字符偏移契约集中 [第 24 号](24-搜索接口界面与验收.md)，尚无这些组件实现。沿用 Vue/TypeScript 和现有 api.ts；前端不得自行生成 embedding、翻译正文或判断依赖兼容。

## 当前拆页契约

| 分组 | 页面 / 路由 | 唯一业务 |
| --- | --- | --- |
| 内容管理 | 制品库 /content/artifacts | 真实入库制品摘要、状态、大小、解析器版本及游标翻页 |
| 内容管理 | 制品详情 /content/artifacts/:digest?parser_version=... | 单份包内名称、版本、内嵌归属、依赖及证据 |
| 作业管理 | 采集任务 /operations/collections | 最近采集作业、取消/重试、进入真实制品 |
| 作业管理 | 新建采集 /operations/collections/new | 单一提交表单，完成后回任务列表 |
| 运维监控 | 存储与额度 /operations/storage | 当前任务及归档数量、预算和容量预留 |
| 系统设置 | 平台配置 /settings | 只读生效限额及存储配置，无任务统计和虚假保存按钮 |

平台根路径是资源/译文目录；工作台旧根重定向规则仅保留在工作台 Router 内。旧 /collections 与 /storage 重定向到对应业务。制品目录直接读 artifacts/scans 摘要接口，不能从最近任务推断内容库；列表不读完整 result JSON，详情才读取 scan。相同制品不同解析器版本分别列出。公开 /search 独立于后台管理连接；作业 /operations/search/jobs 只管理索引处理和重建，监控 /operations/search/status 只显示真实覆盖/水位。模型配置在环境/部署，不混入内容页。菜单归属见第 29、32 号。

App 只保留外壳、菜单、折叠管理连接和错误。轮询只在任务页挂载期间运行；目录、详情、设置、额度按需查询。连接/路由/选择变化中止旧查询、拒绝迟到响应，切页不取消数据库任务。Axios 唯一请求客户端，Pinia 唯一共享状态，DependencyTable 唯一声明表；显示格式和状态名称复用辅助函数。密钥仅在内存，元数据文本转义，不使用 v-html。

每页必须核对桌面/窄屏、空态、错误、加载与真实内容；HTTP 拦截测试必须标识来源。截图与观察记第 27 号，不能以构建通过代替查看图片。

## 迁入页面接线

一个 npm 工程有平台/工作台两个外壳，共用 Vue/Router/Pinia/Axios/navigation，跨外壳使用实际链接。平台普通 HTTP 由 transport.platformFetch 兼容 Response、错误响应体和取消；SSE 保留流通道。旧控制器经 scope 管理定时器、事件与请求；构建不执行独立旧 app.js。构建 CSS 分离，工作台样式不折入平台全局样式。窄屏工作台菜单折叠；平台横向菜单确保当前项可见，组件卸载清理 resize 监听。

镜像设置拆成下载、上游、选源、云存储、同步/分流、客户端加速、CDN，每页 save(section) 白名单提交，其他页草稿保留。CDN 只是规则说明，没有假保存按钮。房间存储归客户端加速，云迁移列表归作业，来源质量观测归运维；不重复显示两排设置菜单。新验收记录见第 31 号。
