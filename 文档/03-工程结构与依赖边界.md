# 工程结构与依赖边界

2026-11-12 依赖约束内核（实施中）：`native/dependency_core` 是独立 C++20 纯领域库，不依赖 Qt、启动器、HTTP、数据库或玩家路径；客户端静态链接，源站 worker 通过明确的 C ABI 使用同一版本的范围判断，不能在 Python 再维护一套近似版本比较。服务端仍复用 Collector 采集事实，客户端原生包内读取与其对齐；纯内核只消费声明及候选值，不下载/解包。未实现的方言明确 unsupported。新增第三方源或派生算法需固定来源、保留许可证和修改说明；用官方语义及共同样例验收，不以数字正则代替版本规范。完整闭包和安装决定仍以第 46 号为准，建立内核文件不代表整套求解已完成。

2026-11-12：加载器/核心目录及停供归 `RuntimeCatalog`，由 Mirror 持有；热门资源和核心共用 `mirror_resources.compatible_releases` 与唯一 `resource_prefetch.compatibility`。发现复用 Inventory/Sources，准备复用 Mirror 作业，位置/预算/删除复用 MirrorCloud 与原存储适配器。RuntimeCatalog 和 GameCompatibilitySettings 复用后台 Router、mirrorWorkspace、共享抽屉及主题，不另建下载器、SDK 或第二套设置。详见第 12、45 号。

## 已落地搜索目录补充

src/bugg_source/search/ 拥有 config/text/clients/repository/worker/service/routes/inference；数据库迁移 migrations/versions/0005_search.py。src/mc_translate/search_export.py 是目录当前正文/译文和增量/可见性的唯一 HTTP 导出，search_gateway.py 连接联邦入口与固定回环查询 API。跨域只通过内部 HTTP，search 不读平台私有 SQLite。前端 SearchView/SearchJobsView/SearchStatusView、SearchResults、stores/search.ts 分别属于公开内容、作业、运维和共享展示。模型准备/隔离夹具/小样例工具及截图脚本各有独立命令，不作为生产启动副作用。完整职责第 12、32 号。

## 目标和实际落点

`src/bugg_source/` 为 Python 包：contracts.py（数据契约）、config.py（配置）、archive.py（受限解压）、parsers.py（纯元数据解释）、collector.py（流程编排）、storage.py（下载和内容存储）、database.py（SQLAlchemy 表和会话）、repository.py（持久任务与快照）、worker.py（独立采集进程）、api.py（FastAPI）、cli.py（命令行组装）。`frontend/` 是 Vue；`migrations/` 是数据库迁移；`tests/`、`tools/`、`文档/` 分别是测试、索引工具与决策。

原平台已完整迁入 src/mc_translate/，42 个模块沿用目录、翻译、账户、联邦、镜像、房间缓存与 TLS 的唯一实现，不再新增重复引擎。reference/platform 保存来源清单和历史参考。auth.py 拥有固定内部会话验证；platform.py 拥有统一子进程启动与清理。

未来增加 search/ 领域模块（未实现）：唯一 tokenizer/查询编译、正文派生投影、检索编排、全文与向量适配器；独立索引 worker 和 embedding 服务。搜索通过 CatalogPort、TranslationPort 读资源/正文版本，通过 SearchPort 隔离索引实现；不依赖 parser 私有字段，不调用 Collector 从网页猜依赖。索引表和现有 SQL 仍由统一数据库/Alembic 管理，API 请求入口和前端请求器继续复用。细分所有权见第 23、24 号。

## 所有权

cloud.py 拥有雨云/S3 profile 与 boto3 校验，archive_worker.py 独立归档执行，沿用 Repository 的数据库/租约规则。frontend/src/views/ 按内容、作业、运维、设置拆页；platform/runtime.ts（路由生成）与 platform/platformRoutes.ts（路由清单） 是唯一页面路由，stores/collections.ts、api.ts 分别拥有会话/请求状态与依赖 DTO 请求。transport.ts 是共享 Axios 实例与旧 Response 兼容层；navigation.ts 为唯一菜单。frontend/src/platform/ 为 Vue/Pinia 页面与共享外壳，frontend/platform/ 为页面控制器清单；浏览器业务控制器仍在 mc_translate/web。原独立工作台 App、Router、HTML 和根主题已删除；admin-workbench.vue 在同一 SPA 中组合既有业务视图，公开搜索使用公开页面组件。页面只组合事实，不持有 SDK 或下载器。目录列表使用 Repository.artifacts 的有界标量查询，不加载 scan.result。Python/前端完整签名分别由第 18、28 号自动索引维护。

| 规则/资源 | 唯一所有者 | 禁止 |
| --- | --- | --- |
| 上游域名、大小、超时 | Settings + ArtifactStore | 路由直接请求外网 |
| 下载、哈希、本地内容寻址 | ArtifactStore | 翻译另写下载器 |
| ZIP 路径、预算、解压证据 | ArchiveReader | parser 自行 extractall |
| 字段、依赖类型语义 | parsers | UI/AI 修改事实 |
| JAR 递归、结果状态 | Collector | API 内解压 |
| SQL 表/约束/索引 | database + Alembic | create_all 自动更新生产 schema |
| 排队、领取、租约、快照 | Repository | worker/UI 各存一份状态 |
| 进程退出/运行循环 | worker | API BackgroundTasks 执行采集 |
| API 客户端/错误呈现 | transport.ts（Axios）+ api.ts（依赖 DTO） | 每页造请求器 |
| 平台目录/译文/账户 | mc_translate.Store 与对应领域 | Repository 跨库写平台表 |
| 镜像/房间分发 | mc_translate.mirror* / room* | 翻译/依赖 API 二次转发文件 |

依赖方向：UI → API → Repository；worker → Collector → Store/ArchiveReader/parsers；Repository → database；所有层共享 contracts。parser 不联网、不执行代码、不接收资源正文。跨域规则经契约交互，禁止互相 import 私有实现。
