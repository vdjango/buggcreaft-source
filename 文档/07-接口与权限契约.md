# 接口与权限契约

## 制品依赖公开查询与缓存入队（2026-11-12，源码基础已实现，未部署）

完整设计及全部安装入口/用户决定见 [第 46 号](46-制品依赖约束与客户端兜底方案.md)。公开 `POST /api/v1/dependency-facts/query` 接受最多 100 个 SHA-256，仅返回显式公开的文件事实；未公开与不存在统一 missing，不触发下载或解析。响应 schema 为 bugg-dependency-facts-v1，按文件返回状态、当前 parser_version 及已有完整快照；管理查询保持原鉴权。

缓存进程以单独 `BUGG_CACHE_INGEST_TOKEN` 调用内部 `PUT/GET /api/v1/internal/cached-artifacts/{sha256}`。PUT 的 kind 为 jar/archive/other，visibility 为 public/private；归档流式接收完整字节并核对摘要后只入原持久队列，解析归 Collector worker。other 只登记不适用状态，不创建“零依赖”快照。镜像对明确的非归档资源直接在源站缓存账本登记不适用，不为每张图片另发 HTTP 请求；未知 ZIP/mrpack/buggpack 仍排队读取，当前未识别清单明确 unsupported。内部凭证不进入启动器、网页或公开查询；未配置时拒绝入队。跨节点 HTTPS，单机回环可 HTTP。失败可重放，成功快照不因重复通知重写。

接收字节上限沿 Settings.max_download_bytes，工作队列及重试沿 Repository；公开结果有总响应预算，超预算项回退客户端受限读取。公开与房间私有文件分别发布，知道私有摘要也不能绕过可见性。新文件在原下载数据流保留四字节文件头，后缀不明但为 ZIP/JAR 的也入归档采集；回填未知文件受限读取文件头，云端/缺失字节不能直接当不适用。此节接口基础已本地测试，递归闭包、客户端及部署仍未验收。

2026-11-12 核心项目清单的可选 `curseforgeProjectId` 标记同一作者的另一发布平台项目，初始仅登记已核对的 Iris 455508。它不是版本替换表：客户端仍须按所选文件 SHA-1 查证同一具体发布，才能复用其固定依赖；未知或不同字节不能按项目名猜测。沿用现有 `/v1/catalog/shader-runtimes`、`/version_file/{sha1}` 和版本查询，不新增 API/任务/数据库。

## 生产代理与缓存边界（2026-11-10）

依赖 API 的成功、鉴权失败、参数错误及未找到响应统一发送 `Cache-Control: no-store`，由 `api.create_app` 的共享 HTTP 中间件负责，搜索路由不单独维护相同规则。公共搜索依然不允许代理缓存；管理接口不得因 CDN 命中绕过身份检查。发布时必须同时检查匿名与已认证请求，并清除历史 CDN 副本；新增响应头不能清除已经存在的缓存。生产端口、旧数据接续与实际验收见第 34 号。

## 启动器官方目录网关

已实现 GET `/v1/catalog/{curseforge|modrinth}/{route}`，只开放官方分类、搜索、项目详情与版本元数据，官方参数/响应保持原义。独立于全文/语义搜索及包内事实查询；不执行文件下载、解压、翻译或安装。路径、数组上限、鉴权、错误、缓存、测试与兼容反代详见 [第 33 号](33-启动器目录筛选与迁移.md)，唯一所有者/资源生命周期见第 12 号。2026-11-10 已部署，实际生产记录见第 34 号。

## 第一阶段接口

| 方法/路径 | 输入 | 输出/错误 |
| --- | --- | --- |
| GET /health | 无 | 数据库和任务表可访问时 ready；不是 worker 心跳或全平台就绪证明 |
| POST /api/v1/collections | CollectRequest | 202 待执行 / 200 已完成缓存；422 非法来源；429 队列满，Retry-After:30 |
| GET /api/v1/collections?limit=50 | 1..100 | 最新任务列表；游标分页第二阶段再实现 |
| GET /api/v1/collections/{id} | 任务 UUID | 状态、attempts、摘要、错误、核验标记；404 |
| POST /api/v1/collections/{id}/cancel | 无 | 当前真实状态；终态幂等返回；404 |
| POST /api/v1/collections/{id}/retry | 无 | 202 入队；409 不可重试；429 队列满 |
| GET /api/v1/artifacts?limit=50&cursor=... | limit 1..100；可选 scan UUID 游标 | ArtifactPage.items 摘要、大小、版本、状态、时间；next_cursor 或 null；400 失效游标 |
| GET /api/v1/storage/status | 管理令牌 | active 队列计数、生效限额、UTC 预算预留及 cloud 配置概况/归档计数；不返回 key、凭据路径或下载 URL |
| GET /api/v1/artifacts/{sha256}/dependencies?parser_version=1.0.0 | 摘要/解析器版本 | 不可变 ScanResult，包括所有模组、依赖、证据、问题；404 未采集 |

依赖管理端支持显式 `Authorization: Bearer ...`（BUGG_ADMIN_TOKEN）或平台 translation_admin 会话。空 Bearer 配置不影响已配置的会话验证；二者皆无时失败关闭。错误 Bearer 不回退 Cookie；Cookie 写入需 Origin 与当前/配置公开源一致。令牌仅作开发管理入口，生产后续补细分 RBAC、速率限制和审计，不把浏览器用户的上游 Key 放前端。任务视图不回传原始 URL，避免签名参数泄漏；数据库 request 仍需受控访问。

## 数据与版本

`declared_name` 只能是包内 name/displayName 或 null。`mod_id`、`version_raw`、`version_resolved`、`loader`、`container_path` 不可混写。`version_raw` 在依赖中可能是字符串、数组或 null，消费者不能自动按普通 semver 处理。`forge_toml` 表示文件格式，避免把早期 NeoForge 的 mods.toml 断言成已验证 Forge。

返回原始 raw 对象用于审计；原始字节通过 evidence.object_key 定位本地，当前没有公开证据下载路由。结果不是安装方案，不能直接产生依赖下载安装动作。未来公共只读 API 单独增加匿名权限、缓存与分页策略，不把当前管理端直接开放公网。

典型提交：`{"url":"https://cdn.modrinth.com/.../file.jar","expected_hash":"...64位十六进制...","hash_algorithm":"sha256","source_provider":"modrinth","source_file_id":"file-version-id"}`。

CollectRequest 增加 purpose=on_demand/warmup（默认按需）。JobView 增加 parser_version、priority、cache_hit；返回同一在途/完成任务 ID 不代表新建记录。cache_hit 是该任务的复用属性，不是每次调用的独立命中事件。额度是保守预留，不是实测流量、桶总账或计费接口。设置页和监控页可读同一状态接口，但各自只呈现所属字段，不能因此混成一个页面。

## 搜索接口当前实现

已实现公共 GET /api/v1/search、/api/v1/search/capabilities、/api/v1/projects/{provider:id}/similar；管理 GET /api/v1/admin/search/status、POST /api/v1/admin/search/rebuilds、POST /api/v1/admin/search/visibility 复用现有鉴权。支持 lexical/semantic/hybrid、正文/当前译文、实际来源片段、有效模式/覆盖/降级。MC+加载器由同一 release 同时满足；上游标签不代表包内验证。分页为共享 PG 五分钟候选会话，无精确全站 total；每页权威复核，撤回/修订立即跳过。HTTP 400 参数、410 会话、429 限流、503 不可用。公开入口经 hub/镜像联邦只读网关，内部导出/推理有独立固定地址和密钥。完整实际契约见第 32 号，草案第 24 号未完成项继续保留。

## 本地平台与内部会话

迁入的 /v1 保留原平台公开合约、安装向导、会话、客户端 Key 和联邦权限，JSON schema 位于 src/mc_translate/contracts。/api/v1 是依赖领域，不能把两个协议的状态枚举混用。auth.AdminAuthorization 只访问配置的 HTTP 回环地址 /_internal/admin-session，传共享内部密钥与单个管理 Cookie；固定 3 秒超时、连接池、禁环境代理/重定向。内部接口验证 loopback、常量时间密钥和实际未过期管理会话。网络异常 503、无效会话 401，不信客户端“已登录”。

Nginx 拒绝公开 /_internal/；内部端口必须保持私有。统一入口自动注入共享内部密钥；分开启动需同值配置。会话在平台内存中，重启需重新登录。本次未增加多角色 RBAC。浏览器不持久化备用 Bearer，默认使用 HttpOnly 管理会话；退出后下一次依赖请求必须失败。

## 2026-11-12 光影核心兼容例外

`GET /v1/catalog/shader-runtimes` 保留候选项目，并返回有上游出处的 `compatibilityRules`。每条仅匹配精确 publisher/projectId/versionId、gameVersion、loader 和 minLoaderVersion；不是从简介或文件名推断的包内事实，也不重写作者固定依赖。当前已确认例外为 NeoForge 26.3.0.65 起与 Sodium 0.9.2/Iris 1.11.7 固定依赖的接口冲突。启动器排除该组合并解释原因；不能用只升级 Sodium 的方式绕过 Iris 约束。正常旧加载器和其他游戏版本不受该条影响。响应禁止缓存，启动器会话内仍使用原有有界短缓存。
