## 搜索进程补充

platform 在启用搜索且非镜像角色时启动独立 search-worker；模型由 embedding-serve 显式启动，API 不下载模型。SearchClients/Engine 在 API lifespan 或 CLI finally 关闭；HTTP/推理位于数据库事务之外。feed 租约 60s、项目 120s，每批续约并在发布时核对 token/源修订；进程硬退出等待到期，最多五次重试，管理员可重建。所有同库 worker 必须同配置，升级先停旧进程，不能混用模型。浏览器离开时取消查询/相似请求、停止作业轮询、拒绝过期响应；取消浏览器重建 POST 不撤销已经接受的后台工作。具体路径及恢复见第 12、32 号。

每次涉及后台、取消、退出时必读本页。API Engine 由 create_app 创建、lifespan 退出 dispose；CLI/worker Engine 在 finally 释放。HTTP Client 每次下载使用 with 关闭；ZIP 和成员流使用 with；暂存文件 finally 清理，不把资源所有权交给 Vue 页面。

任务属于数据库，不属于 HTTP 请求或浏览器。断开浏览器、切换页面不会自动取消；用户 cancel 才标记。worker 的停止 Event 在 checkpoint 中触发 WorkerStopping，并归还队列；硬退出等待租约到期恢复。网络取消最坏受 socket 超时限制，当前不是可立即打断的 async transfer；不宣称毫秒级强制终止。

心跳和 finish 同时检查领取 token/状态/过期时间；旧 worker 失去租约不能提交。完成事务再次检查取消，取消后不能发布成功 scan。部分下载或半解析结果不写入成功快照；已完整保存的 CAS/证据可能因取消成为孤立对象，后续 GC 处理。

同一时刻每 worker 一个任务，禁止在页面另开下载器、在 API BackgroundTasks 保存只在内存中的队列。PostgreSQL 多 worker 通过 SKIP LOCKED；SQLite 仅单 worker。进程配置和解析器版本一致；升级扫描规则生成新版本快照，不覆盖旧结果。

ArchiveWorker 已加入，复用 Worker 循环/停止和 Repository 闸门，独立进程持有 boto3 Client，由 CLI finally close；网络调用不能即时中断，哈希/SDK 调用间 checkpoint 续租。首次领取容量保守保留，失败不会退款；重试新的领取预留新的每日上传预算，旧 token 不得提交。事实提交和归档执行分开，上传失败不影响既存声明。

Vue 会话连接、目录、详情、任务列表、存储查询各有独立取消控制器；会话 generation 拦截迟到响应。只有任务页挂载时有一个 interval，离开清理；详情/游标变更取消旧查询，取消后的错误不覆盖新页。新建页面离开后 POST 即使成功，也不跳回任务页；后台作业不会因切页消失。API lifespan 关闭 Engine，浏览器不拥有数据库任务。

译文/目录已迁入，沿用 aiohttp cleanup context 和既有 engine/Store 调度的创建、关闭、重试与恢复，不能另造业务状态。生产资源限额/退出宽限期尚待第 10 号落实，compose 仍仅开发数据库。

## 统一平台进程

platform.run_platform 启动同一解释器的 hub、mirror、FastAPI 与 0..16 个采集 worker；只有明确云 profile 才加 archive-worker。端口启动前校验不同且有效；共享内部会话密钥只经子进程环境传递。任一子进程退出则统一入口失败并清理其余子进程，SIGINT/SIGTERM 触发退出；Linux 发送 SIGTERM，Windows terminate，最多共等 10 秒后 kill，硬退出任务由原租约恢复，不虚报优雅归队。迁移需显式 db-upgrade，启动不暗改 schema。

FastAPI lifespan 持有一个有界 httpx 管理会话验证客户端，关闭时 aclose；平台账户会话不复制到事实库，重启平台使旧会话失效。镜像私有账本仍由镜像进程唯一持有，不与平台 Store 或事实 Repository 并写。
