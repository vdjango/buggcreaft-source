# 后台菜单与业务信息架构

2026-11-12：镜像内容组新增唯一“加载器与核心” `/admin/mirror/runtimes`。目录/停供归内容管理；兼容配额与加载器/核心开关在同页“缓存规则”维护，热门设置仅链接、不复制。运行中传输/失败重试继续归原作业页，禁止再增任务列表或主题。保存边界见第 20、45 号。

后台按五组组织，菜单唯一来源 frontend/src/navigation.ts。所有管理页面复用平台 Router、SiteNav、AdminNav、AdminAccess 与同一套主题变量；移除独立依赖 App、Router 和 CSS 根主题。兼容保留 /content、/operations、/settings 管理地址，必须识别为后台，不能落回公开首页。当前页及详情保持父项高亮，窄屏菜单滚动到当前项。

2026-11-11 用户纠正：公开资源与译文 `/`、资源搜索 `/search` 不属于后台菜单，不能借内容管理入口把管理员带到首页。后台只展示实际管理、作业、状态和配置；公开搜索保留在站点公开导航，不作为后台功能。后续新增菜单必须同时验证目标路由、管理认证和同一主题，不能只校对菜单文案。

表中 resources/temporary/sources/tasks/transfers 是 /admin/mirror 下的完整子路由。项目 /projects/:provider/:id 是资源子页；制品 /content/artifacts/:digest 是制品子页；/operations/collections/new 是采集子页，均不建一级菜单。旧 /admin/traffic、/admin/usage 仍兼容，归监控，不重复添加菜单。

## 设置的字段所有权

| 页面 | 可保存内容 | 排除 |
| --- | --- | --- |
| downloads 下载策略 | 下载开关/公开入口、各类别 policies 与普通资源 routes | 不保存来源、质量或房间 routes 草稿 |
| sources 上游来源 | 仓库列表、自动映射/优先国内/清理替代副本 | 来源表现放运维 |
| quality 选源规则 | 采样开关、预算、阈值、周期/排序规则 | 不混观测列表 |
| cloud 镜像存储 | 云空间/本地额度、保护/淘汰、签名链接策略 | 不放房间额度和云迁移任务表 |
| storage 同步与分流 | 自动同步/并发/预热平台、节点/出口预算 | 实际同步记录去作业 |
| room-cache 客户端加速 | 临时文件启用/TTL/上限/查源、房间类别 routes、临时存储额度 | 普通游戏资源 routes 不在本页改 |
| cloudflare 域名与 CDN | 当前域名规则说明与复制 | 无保存 API，不放假保存按钮 |
| 翻译/邮件 | 各自提供商、预算或 SMTP/通知配置 | 不显示镜像内容列表 |
| /settings 依赖采集配置 | 只读当前限额、归档配置 | 统计去 /operations/storage |

mirrorWorkspace.save(section) 白名单构造提交并调用原配置 API，只更新该域已提交基线，其他域草稿保留；共用 routes 时与服务器基线合并，不能提交其他页未保存 routes。云上传暂停/恢复是独立即时控制，不随保存覆盖。该行为有直接回归测试。

搜索内容位于公开 /search，作业管理增加 /operations/search/jobs（重建/处理记录），运维增加 /operations/search/status（真实覆盖/水位/模型空间）；模型连接由部署环境管理，内容页不堆设置或作业控制。人工完整审核仍未完成，不建空菜单或虚构覆盖率。迁移页面逐图见第 31 号；本轮新增搜索页逐图见第 32 号，继续维护第 08、12、18、28 号。
