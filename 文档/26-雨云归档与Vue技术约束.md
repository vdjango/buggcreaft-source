# 雨云归档与 Vue 技术约束

> 本页保留依赖归档最初设计。完整源站迁移后，原镜像存储实现已在本仓库 src/mc_translate/mirror_storage.py，两个领域沿用各自队列/预算与独立前缀；“不复制旧镜像”是早期审计决策，当前已有实现及过渡边界以第 30 号为准。

## 本轮补充要求与旧站复用审计

用户明确已有雨云存储，并要求 Vue 全家桶及 Axios。只读审计旧站 `src/mc_translate/mirror_storage.py:S3Storage`、`tests/test_s3_storage.py`、`docs/雨云存储与自动HTTPS.md`：旧版用 boto3/botocore、S3v4、独立凭据文件、私有签名 URL、上传前哈希与上传后校验。旧站 aiohttp 生命周期、镜像类别和账户证书配置不适合作为新站运行依赖；复用 boto3 官方库及相同配置/验证约定，不复制完整镜像调度或自行实现签名协议。

本轮使用雨云原始 HTTPS S3 endpoint 签名，不改写签名后的域名，不接管旧站证书/域名、不读取旧站凭据内容或修改旧服务。支持显式指定旧格式配置文件与 profile ID，再显式指定同结构凭据文件；没有配置时本地模式正常工作。新对象位于独立 bugg-source/v1 子前缀，不能混淆旧站已跟踪的存储对象。

## 归档数据流与可靠性

完整 JAR 本地落地 → 本地受限解压/扫描 → 数据库保存事实及待归档对象 → 独立 archive-worker 读取 → boto3 上传与 HEAD 核验 → 记录 succeeded。归档涵盖 JAR 和所有解压证据，内容按摘要寻址；不在 API 或采集进程中等待云上传。归档失败不撤销已经成立的包内事实，也不伪装归档成功。

archive_objects 是幂等持久对象清单/上传队列，以空间身份+对象 key 唯一；保存本地相对路径、哈希/大小、状态、租约/token、次数和错误。首次领取原子预留容量，之后即使失败仍保留，重试不重复占容量；每日上传预算按每次领取预留，重试不退款。容量和预算只统计本平台独立前缀，不代表桶总账或其他服务用量；上传预留包含 SDK 最大三次尝试。

参考雨云已验证的服务端 SHA-256 行为，本轮使用有界单 PUT（默认最大 256 MiB），提供 ChecksumSHA256，上传前验证本地哈希和大小，HEAD 校验服务端 checksum 和长度；同 key 不同内容拒绝覆盖。远端已存在且核验匹配可幂等完成。所有 SDK 调用有连接/读取超时和有限重试；在哈希/调用之间续租，上传中的停止/取消受 SDK 网络调用限制，不承诺即时打断。

本轮归档是本地+云副本，**不自动删除本地 JAR/证据**，不提供任意对象公开下载或云 GC；云优先缓存需要先完成按引用回收、云还原完整性与并发读保护。本轮未运行真实云上传，本地 Stubber 不等于雨云联调。

## Vue 全家桶与 Axios

确定使用 Vue 3 Composition API + Vue Router 4 + Pinia 3 + TypeScript + Vite，Axios 为唯一 HTTP 客户端；Vitest 验证共享状态/请求竞态。路由页面按需加载。令牌保持 Pinia 内存，不放 URL/localStorage；请求 timeout 和 AbortController 取消统一封装，鉴权/错误统一处理。

采集页面复用已有依赖表，新增存储/预算只读页面显示真实服务端状态；不在依赖工作台配置云密钥或上传文件。连接切换、任务切换、路由离开后旧请求不能覆盖新状态，定时轮询由页面生命周期启动/清理，禁止每个组件另开轮询。完整迁移后生产分流采用 deploy/nginx.conf：平台 hub 按路由返回对应页面外壳，不能把整站请求统一 fallback 到工作台 index.html。
