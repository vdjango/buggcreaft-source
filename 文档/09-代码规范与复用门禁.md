# 代码规范与复用门禁

新增搜索适配 search_export.py/search_gateway.py 虽位于历史 mc_translate 目录，仍须显式执行 Ruff check/format；CI 已单独登记这两文件，历史批量排除不适用于新文件。自动 Python/前端符号索引包括新适配、推理/评测/夹具/截图工具和测试，不能因脚本或私有方法而漏记。

每次先 `rg -n '职责词|符号名' src tests 文档/18*`，再查第 02 号旧能力映射。记录检索、不能直接复用的原因、唯一所有者、直接测试。新方法不只检查同名；网络、哈希、ZIP、SQL、任务状态各自只有一个所有者。

Python 使用类型标注、Pydantic 跨层 DTO、Ruff 格式与检查；不吞掉异常后返回伪成功。纯 parser 不依赖 HTTP/SQLAlchemy。框架默认方法不重复封装成空转发器。测试直接验证字节到事实、异常、恢复、权限与证据链，不测试 getter。

Vue 使用 Composition API + TypeScript + Router + Pinia，共享 Axios 在 transport.ts、依赖 DTO 在 api.ts；表格和格式辅助函数共享。包内元数据禁止 v-html，迁入的正文渲染沿用服务端清洗与原安全测试，不把未清洗介绍插入 HTML。状态从 API 查询，不靠动画推导进度。菜单按第 29 号分内容、作业、运维、接入、设置，不在单页堆全部模块；实现后的每页按项目视觉 Skill 实际打开并查看截图。

每个新增 Python 类/函数/方法由 `python tools/update_method_index.py` 生成第 18 号，前端在 frontend 执行 `npm run methods` 生成第 28 号；各自 --check / methods:check 在 CI 阻止漏记。第 12 号登记行为契约，第 08 号登记前端页面/生命周期。签名包括私有、测试和工具回调，不用自动清单代替设计。

提交前执行 Ruff、pytest、Python 索引检查；前端修改执行 npm test、methods:check、build 和相关浏览器视觉验收。无 PostgreSQL 明确跳过，不把 SQLite 当多 worker 证据；SDK Stubber 不当作真实雨云上传。

## 迁入代码的格式与检查范围

mc_translate 和 tests/platform 保留历史格式，reference 为归档参考；Ruff extend-exclude 明确排除这三处，避免迁移时产生无关全文件重排。新增 bugg_source/auth/platform、工具、集成测试仍执行 Ruff 全规则。迁入代码不是免验收：全部加入 pytest、前端类型/构建、索引和页面验收。前端旧 JS 控制器也加入 AST 索引，不能漏记私有函数；生成 vue-* 不纳入源码索引。
