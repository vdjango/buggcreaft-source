# 成都分发与完整房间缓存

日期：2026-11-11。本次正式入口已切换为用户指定的 https://mirror.bugg.icu/；以下成都部署段为当前事实，旧性能数据与原生节点未完成项分别保留。

## 实现和使用

房主继续使用启动器已有的“加速缓存”开关、清单和逐文件上传进度，不增加测速按钮。管理端“客户端加速”提供按需缓存、完整缓存；默认按需保持既有行为。完整模式先检查相同 SHA-256 的已验证对象，没有才请求房主补齐模组、资源包和光影。改名、不同房间引用同一文件不重复上传。保留期限默认 8 小时，并非永久归档；单文件、容量、授权和到期清理仍有效。容量不足返回原有 pending/原因，客户端不会当作全部就绪。

完整模式属于源站策略，不把低速检测、缓存决策复制到启动器。按需模式复用 SourceQuality、来源目录和有限探测预算；成都慢速阈值为 512 KiB/s。本轮没有新增每次下载前测速、低速时盲目加线程或新的客户端下载器。

“镜像存储”可添加本地目录/挂载磁盘、雨云、S3/OSS 兼容或七牛空间，并按类别混用。LocalStorage 扩展既有适配契约，复用 MirrorCloud 队列、配额预留、逐文件进度、摘要身份与到期清理。复制和哈希在工作线程中流式执行，验证成功才原子发布；缺失目录不自动创建。额外挂载路径先完成挂载并授予 bugg-source 写权限，再在页面选择；ProtectSystem=full 允许 /mnt、/srv 等数据路径按 Unix 权限访问，系统目录保持只读。

本地空间下载复用 FileResponse 的 HEAD、Range、416、ETag 与现有正在服务计数；使用域隔离 HMAC 限时链接，无匿名列表。访问日志不记录签名。普通镜像和房间文件共用准入，不另建无界连接池或任务账本。具体契约在第 04、12 号。

## 成都实际部署

- 公网 IPv4 `1.14.48.161`、IPv6 `2402:4e00:c000:1800:ae:a5fc:b6aa:0`；2 CPU、约 7.5 GiB RAM。根盘约 79 GiB，初次审计可用约 69 GiB。赠送的 50 GB 磁盘尚未挂载，未虚构可用容量。
- 成都和上海 `/opt/bugg-source/current` 均指向 `releases/20261111-storage-domain-r4`。成都 `bugg-mirror-edge.service` 独立运行 mc-mirror，绑定回环 18450；Nginx 监听 IPv4/IPv6 80、443。目录、译文、账号和事实 API 继续在上海；没有另建事实 hub。上海的管理桥经本机 18460 SSH 转发连接成都，不再启动本地镜像写入者。前端以线上源码为基底，仅叠加本次存储改动，保留未发布的其他窗口整站改版。
- 普通默认缓存暂存 8 GiB，新增指定目录空间 `chengdu_disk`：`/var/lib/bugg-source/storage`、30 GiB；房间保留 8 GiB，中转暂存 1 GiB；磁盘至少留 10 GiB。完整缓存开启，单文件上限 2048 MiB，回源并发 4，正在分发请求上限 32。配置由实际成都 Mirror 管理，后台已上线。游戏核心/原版资源/依赖库/Java 的目标为成都目录；下载策略沿用既有设置（部分只重定向，不擅自全量下载）。加载器、模组、房间等原雨云路由保留，可在后台按类别切换或双份保留。
- 原上海缓存账本、完整 Mirror 状态、NodeAccess、云凭据和房间 issuer 信任迁至成都；保留原主机备份。2,360 条缓存映射、雨云 2,364 个文件位置保留，无批量重新上传。存储配置和文件位置由单进程管理；远程失联返回 503，不写管理站上的假配置。已绑定文件的空间不能更改根目录或对象身份。
- `mirror.bugg.icu` 经 CDN 回源成都，根页面及状态 200，响应含 `X-Bugg-Origin: chengdu`；目录网页反代原上海 hub，文件字节在成都提供。管理接口匿名 401/no-store，`/_internal/` 404，签名本地文件私有/no-store；Nginx 不记录签名访问日志。不是给启动器增加第二个源地址。
- DNSPod DNS-01 已实际签发回源新证书，有效期至 2027-02-09；Certbot renew --dry-run 成功。`bugg-source-certificate.timer` 每日两次检查，部署钩子验证 Nginx 后重载，凭据 `/etc/bugg-source/dnspod.ini` 为 root 600。退役上海仅 mirror 域名的旧 HTTP 续签配置，保留其他域名续签；没有打印或打包密钥。CDN 边缘使用独立 DigiCert 证书，实测有效期至 2027-02-04；该证书由 CDN 控制台管理，本次 DNSPod 定时器负责回源证书，不冒充已接入阿里 CDN 证书更新接口。
- 共享 200 Mbit/s 出口使用 HTB/fq_codel，IPv4/IPv6 分别分类：总上限 190 Mbit/s，HTTP 上限 170 Mbit/s，SSH 控制和中继优先；空闲容量可借用。与按最近一分钟预估字节的 Egress 准入是不同层次。脚本先在临时 dummy 设备验证，再启用 systemd 持久单元；未关闭防火墙。
- 源码和单元在 `deploy/`；旧 release 保留，可将 current 指回旧目录并重启 edge 回退。取消带宽调度可禁用对应单元并恢复 eth0 根 qdisc；无需改动源站数据或启动器入口。
