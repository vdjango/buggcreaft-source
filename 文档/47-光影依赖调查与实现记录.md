# 光影依赖调查与实现记录

时间：2026-11-12。状态：实施中；本记录不是全版本兼容报告，也不是发布验收。

## 已取得的文件证据

对 Modrinth Iris 版本目录中声明支持 Minecraft 26.1.1 + NeoForge 的四个发布，下载主文件并核对 SHA-512。原始目录快照和文件声明分别保存在 [Iris 目录快照](../data/validation/shader-26.1.1/iris-upstream-snapshot.json) 和 [文件核验记录](../data/validation/shader-26.1.1/iris-artifact-audit.json)。

| Iris 发布 | 平台列出的必需依赖 | JAR 声明的 Sodium 依赖 | 安装和运行 |
| --- | --- | --- | --- |
| 1.11.4+26.1-neoforge | 指定 Sodium 发布 | `[0.6,)`，必需 | 未验证 |
| 1.11.3+26.1-neoforge | 空 | `[0.6,)`，必需 | 未验证 |
| 1.11.2+26.1-neoforge | 空 | `[0.6,)`，必需 | 未验证 |
| 1.10.9+26.1-neoforge | 指定 Sodium 发布 | `[0.6,)`，必需 | 未验证 |

四份文件均声明与 Embeddium 不兼容。平台声明游戏版本可用，并不等于平台依赖列表完整；文件声明范围也不等于已验证具体的加载器构建和依赖组合。

## 26.1.1 + NeoForge 的复现和修复证据

以 Minecraft 26.1.1、NeoForge 26.1.1.15-beta 和 MakeUp 光影包，在隔离实例中复现启动器规划报“必要依赖未能匹配”。Iris 1.11.4 的平台记录声明支持该游戏版本，但固定的 Sodium 发布 `zg4YQ9EL` 只声明 26.1.2；Iris 1.10.9 固定的 Sodium `Fg5Mk6Y3` 声明包含 26.1.1。平台目录证据保存在 [依赖冲突记录](../data/validation/shader-26.1.1/iris-sodium-catalog-conflict.json)。

启动器现在会在候选依赖不能满足时尝试其他候选，之前的中间版本在隔离目录中通过真实下载及安装测试，得到光影包 ZIP 和核心相关 JAR；该测试没有启动 Minecraft，不能证明游戏内光影生效，也没有证明所用加载器是最新版。最新改动还需要重新编译并重跑该测试才能计入最终验收。

CurseForge 同样提供具体文件的游戏版本和加载器信息：[Iris 1.10.9 的 NeoForge 文件](https://www.curseforge.com/minecraft/mc-mods/irisshaders/files/7867946)列出 26.1、26.1.1、26.1.2；[Fabric 文件](https://www.curseforge.com/minecraft/mc-mods/irisshaders/files/7867943)也列出这三个版本。[Modrinth Iris 1.11.3 发布页](https://modrinth.com/mod/iris/version/1.11.3%2B26.1-neoforge)同样提供 26.1 系列及 NeoForge 支持信息，上表对应的 API 快照记录了具体游戏版本及依赖。上述平台信息属于作者声明，不能代替实际安装和世界内验证。CurseForge 的 [Oculus 项目](https://www.curseforge.com/minecraft/mc-mods/oculus) ID 为 581495；这是候选项目身份，不代表其支持所有 Forge 游戏版本。

之前另行手工验证过 Minecraft 26.3 + NeoForge 26.3.0.101 组合进入世界并启用光影；那是手动组合，不能代替启动器自动安装验收或推广到其他游戏、加载器和核心版本。

## 当前代码进展

源站受信发布观察可对已登记核心的空平台必需依赖建立持久待审核线索，按具体游戏版本查找并追加人工结论。空依赖仅是线索，不自动认定错误或发布为已验证组合；管理 API 使用现有鉴权，审核人字段由操作者填写。当前覆盖清单中有平台项目 ID 的 Iris/Oculus 来源，未登记的来源项目尚未纳入。

启动器依赖修复候选增加来源、项目和发布身份核对，避免把其他项目返回的文件作为当前项目的替换候选。已有包内依赖检查和求解源码仍需完成端到端验证；对于平台为空且缺少可信项目映射的依赖，现阶段不能声称能够自动补装。

内容规划会自动为光影包选择目标游戏和加载器的核心；本轮修正内容列表分页位置串入核心和依赖查询的问题，并在登记了 CurseForge 项目 ID 时增加候选回退。两平台不同文件仍按各自发布与依赖独立处理，不根据项目对应关系假定文件内容相同。已有安装记录的 CurseForge 核心复用时，重新查询确切发布并比对文件摘要；没有受信安装记录且未被 Modrinth 识别的文件仍需完善识别。人工标记应针对具体游戏、加载器构建和文件组合记录可用、不可用或待验证，不能替代自动添加；完整标记发布和消费尚未实现，不能据此称双平台闭环已完成。

本地受控测试覆盖 Fabric、NeoForge、Forge、Quilt 的候选选择、分页隔离、CurseForge 回退及已登记核心复用、摘要或加载器不匹配、切换版本后的旧响应，以及修复候选身份和原子提交；这些是模拟响应，不代表真实游戏安装通过。源站审核入口和发布采集的定向测试 6 项通过，使用本地 SQLite。尝试直接查询 NeoForge Maven 确定最新构建时连接超时，不能据此确定 26.1.1 的最新加载器版本或声称已安装。客户端本地兼容规则测试及源站清单测试还存在既有失败，见下列限制。
